
# Project: Feed The News

Feed The News is a donation app for journalism, like a monthly Go Fund Me
specifically targetting journalism and to start with, soccer journalism in the US.

## Always

* **Always** use Unix line endings for all source file
* **Always** put a newline at the end of ever source file

## Never

* **Never** change the line wrapping on an existing file to make the lines longer

## Stack

This app is a SvelteKit application to implement the web user interface for the
Feed The News application.
It gets data from a GraphQL API.

`make code` regenerates the GraphQL libraries
